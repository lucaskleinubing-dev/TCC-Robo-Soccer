# TCC-Robo-Soccer
Projeto de Trabalho de Conclusão de Curso (TCC) desenvolvido no Instituto Federal Sul-rio-grandense (IFSul) – Câmpus Lajeado, voltado ao desenvolvimento de um robô autônomo para a categoria RoboCupJunior Soccer.
O projeto integra mecânica, eletrônica, motores de passo, sistemas embarcados e visão computacional, utilizando um Arduino Mega, drivers A4988, motores de passo e um módulo ESP32-CAM com câmera OV5640. Para a detecção da bola, 
é utilizado um modelo baseado em YOLO, treinado por meio da plataforma Edge Impulse.
O objetivo é desenvolver e avaliar uma alternativa de locomoção baseada em motores de passo, além de implementar os sistemas necessários para percepção e navegação do robô em campo.
